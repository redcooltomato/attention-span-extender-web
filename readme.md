# Swoon

This (currently firefox) extention attempts at fixing your attention span by *swooning* (turning to black pages) domains from the list of your choosing

Kinda WIP as of now

# Reasons to exist

Despite the abudance of similiar plugins, I made this one to be as minimalistic as possible
